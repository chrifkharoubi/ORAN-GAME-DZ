# GAME SHOP ORAN — متجر ألعاب فيديو

## التشغيل
1. افتح `index.html` في المتصفح.
2. ضع صور المنتجات داخل مجلد `img` بالأسماء الموجودة في `script.js`.
3. الموقع يعمل بدون قاعدة بيانات.
4. الطلبات تُرسل مباشرة إلى WhatsApp.

## صور المنتجات
الأسماء المتوقعة:
- ps4.png

إذا لم توجد صورة، سيظهر رمز Gaming بديل تلقائياً.

## تعديل رقم WhatsApp
افتح `script.js` وابحث عن:
`const whatsappNumber="213560602585";`

واستبدله برقم WhatsApp الخاص بالمحل بصيغة دولية بدون + أو مسافات.

## تعديل المنتجات والأسعار
كل المنتجات موجودة في بداية `script.js` داخل `PRODUCTS`.
يمكنك تغيير الاسم والسعر والصورة والفئة.

## ملاحظة
الموقع مصمم كواجهة طلب عبر WhatsApp، ولا يحتاج إلى نظام دفع إلكتروني أو قاعدة بيانات في هذه النسخة.
